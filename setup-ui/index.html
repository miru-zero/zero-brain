สมองกลาง domain-agnostic · local-first · offline · ไม่มี network call · v1.2

ขั้นตอนติดตั้ง

1. clone โค้ด (repo public — โค้ดล้วน ไม่มีเนื้อสมอง)
$ git clone https://github.com/miru-zero/central-brain.git
2. ติดตั้ง + build (ต้องมี Node.js ≥ 18 และเน็ตครั้งเดียวตอน npm install)
$ cd central-brain && npm install && npm run build
3. ต้องผ่านก่อนไปต่อ — smoke test 45 ข้อ (T2 gate / provenance / nightly / scanner)
$ node test/smoke.mjs
ผลที่คาด: ผ่าน 45/45 — ถ้าไม่ผ่าน ห้าม install ให้รายงาน error ก่อน
4. วางเนื้อสมอง — แตก Central_Brain_seed จาก pack zip ไปไว้ที่ brain root (เช่น M:\Central_Brain)
ห้ามวางในโฟลเดอร์ clone · ห้าม commit ขึ้น git · เนื้อสมองอยู่ local เท่านั้น (กฎเหล็กข้อ 5)
5. สร้าง MCP config จากตัวกำเนิดด้านล่าง แล้ววางใน config ของ client ของคุณ
6. เปิด client แล้วเรียก brain_health — เห็น 58 notes / 0 dead_links = สำเร็จ

ตัวกำเนิด MCP config

กฎเหล็กที่ติดตั้งมาพร้อมระบบ

ไม่มี delete ใดๆ — ซ่อนได้ด้วย state: archive เท่านั้น · manifest/links/audit เป็น append-only
โน้ต atomic/entity ต้องมี evidence ≥ 1 ไม่งั้น server ปฏิเสธ
T1 อ่านได้แต่ถูก audit ทุกครั้ง · T2 ถูกบล็อกจนกว่าเจ้าของสร้าง .kb/approvals/<id>.json ด้วยมือ — agent อนุมัติตัวเองไม่ได้
ไม่มีทริกเกอร์ = ไม่อ่าน · server อ่าน env แค่ CENTRAL_BRAIN_ROOTCENTRAL_BRAIN_ACTOR เท่านั้น
